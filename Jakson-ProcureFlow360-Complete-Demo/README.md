# JAKSON ProcureFlow 360 - Complete Demo

A presentation-ready enterprise procurement demo covering BOQ to material consumption.

## Run locally
```bash
npm install
npm run dev
```
Open the URL shown in the terminal (normally http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Included
- Premium responsive executive dashboard
- 20 procurement modules
- Project, WBS, BOQ, indent, approval, sourcing, PO, MFC, inspection, dispatch, GRN, consumption, invoice and closure screens
- Interactive workflow, search, role selector, notifications, dark mode, tables, charts and demo forms
- Realistic mock data and local UI interactions

## Important
This is a functional frontend demo with mock data. SAP S/4HANA, Wrench, ProcurEngine, Azure AD and database connections are represented as integration-ready UI states and require real credentials/APIs for production deployment.
